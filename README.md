# Bot de Alertas de Ofertas no Telegram

Bot desenvolvido em Python para monitorar canais do Telegram e enviar automaticamente ofertas que correspondam a palavras-chave configuradas.

## Funcionalidades

- Monitoramento de múltiplos canais do Telegram.
- Filtragem de mensagens por palavras-chave.
- Envio automático de ofertas com textos e imagens.
- Comandos para adicionar e remover palavras-chave.
- Gerenciamento dos canais monitorados.
- Armazenamento do progresso das mensagens analisadas.

## Tecnologias utilizadas

- Python
- Telethon
- Telegram Bot API
- Requests
- JSON
- Programação assíncrona

## Sobre o projeto

O projeto foi desenvolvido para automatizar a busca por promoções em canais do Telegram, permitindo acompanhar ofertas de produtos específicos sem precisar verificar manualmente cada canal.
